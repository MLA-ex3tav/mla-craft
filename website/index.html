Requisitos

Lo que tu PC debería tener

Mínimo

  • Sistema Windows 10 (64 bits)
  • Procesador 2 núcleos a 2 GHz
  • Memoria 4 GB de RAM (2 GB libres para el servidor)
  • Disco 1 GB para la app y el primer mundo
  • Red Conexión a Internet para descargar el servidor y Java

Recomendado

  • Sistema Windows 11 (64 bits)
  • Procesador 4 núcleos o más
  • Memoria 16 GB de RAM (6-8 GB para el servidor)
  • Disco SSD con 10 GB libres para mundos y backups
  • Red Subida estable para jugar con amigos

Preguntas

Dudas frecuentes

¿Necesito saber algo de Java o de la terminal?

No. Eliges el tipo de servidor y la versión, y la app se encarga del resto: descarga el .jar, instala el runtime de Java que corresponde y arranca el servidor.

¿Puedo jugar con amigos de otros lugares?

Sí. Puedes abrir el puerto en tu red y compartir tu IP, usar un túnel, o instalar la app en un equipo o servidor remoto y administrarlo con el panel. MLA Server incluye un modo de administración remota con usuario y contraseña.

¿Dónde se guardan mis mundos y copias de seguridad?

En la carpeta que elijas al crear cada servidor. Todo es tuyo y visible: la app no sube tus mundos a ningún servicio.

¿Puedo instalar mods y plugins de terceros?

Sí. Buscas dentro del panel, instalas con un clic y puedes activar, desactivar o borrar cada archivo. También puedes añadir un .jar desde el explorador de archivos.

¿Es realmente gratis?

Sí. Puedes descargarlo y usarlo sin límites, sin registro y sin telemetría.

¿Cómo actualizo a una versión nueva?

Descarga el instalador del último release y ejecútalo encima. Tus servidores, mundos y ajustes se conservan.
